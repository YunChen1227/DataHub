# 身份证三要素核验接口 — 延迟测试说明

> 对应上游接口文档：`docs/身份证三要素核验接口文档.docx`

本文档用于在**服务器侧**直接调用上游「身份证三要素核验」接口，并统计单次/多次调用的网络与服务耗时，便于评估延迟。

---

## 1. 接口信息

| 项目 | 说明 |
|------|------|
| 接口地址 | `https://api.cqcucc.com:8443/api/idCardThreeElements` |
| 调用方式 | `POST` |
| Content-Type | `application/json;charset=UTF-8` |
| 字符集 | UTF-8 |

### 1.1 请求参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `appId` | String | 是 | 平台分配的调用方 Id |
| `outBizNo` | String | 是 | 调用方生成的唯一订单号 |
| `name` | String | 是 | 待核验用户姓名 |
| `idCard` | String | 是 | 待核验用户身份证号（支持 15/18 位） |
| `profilePicture` | String | 是 | 人像照片 Base64（原始大小与编码后均 ≤ 50K；去掉 `data:image/...;base64,` 前缀） |
| `timestamp` | Long | 是 | 毫秒时间戳，与服务器时间误差 ≤ 60 秒 |
| `signature` | String | 是 | 报文签名（见下文） |

### 1.2 签名规则

1. 除 `signature` 外，所有字段按 **key 字典升序** 拼接：`key1=value1&key2=value2&...`
2. 末尾追加：`&AppSecret=` + 商户密钥（注意 `AppSecret` 大小写）
3. 对整串做 **SHA256**，输出小写 hex，即为 `signature`

参与签名的字段包括：`appId`、`outBizNo`、`name`、`idCard`、`profilePicture`、`timestamp`（签名串中 timestamp 用字符串形式）。

### 1.3 响应说明（节选）

成功示例：

```json
{
  "Code": 0,
  "Message": "请求成功",
  "IsCharge": true,
  "OutBizNo": "123456789",
  "Data": {
    "Result": 1,
    "ResultMessage": "姓名与身份证号匹配，识别为同一人",
    "ImageScore": 932.26
  },
  "RequestId": "3nEJDJRGRiECzCR9Mgs7vn"
}
```

常见错误码：`405` 签名校验错误、`461` 照片大小不符合要求、`462` 未检测到人脸等。完整列表见原接口文档附录 5.1。

## 2. 测试方式

### 2.1 准备

1. 向商务经理获取：`appId`、`AppSecret`
2. 准备一张合规人像照片（JPG/PNG/BMP，Base64 后 ≤ 50K）
3. 将测试脚本上传到服务器：

```text
docs/身份证三要素核验/test_idverify_latency.py
```

4. 服务器需有 Python 3（`python3 --version`）。脚本**仅用标准库，无需 pip install**。

### 2.2 环境变量

| 变量 | 说明 |
|------|------|
| `IDVERIFY_APP_ID` | 上游 appId |
| `IDVERIFY_APP_SECRET` | 上游商户密钥 |
| `IDVERIFY_BASE_URL` | 可选，默认 `https://api.cqcucc.com:8443/api/idCardThreeElements` |

### 2.3 单次调用（看一次完整响应 + 耗时）

```bash
export IDVERIFY_APP_ID="你的appId"
export IDVERIFY_APP_SECRET="你的AppSecret"

python test_idverify_latency.py \
  --name 张三 \
  --id-card 420101198012010011 \
  --photo /path/to/face.jpg
```

### 2.4 多次压测（统计 min/max/avg/p50/p95）

```bash
python test_idverify_latency.py \
  --name 张三 \
  --id-card 420101198012010011 \
  --photo /path/to/face.jpg \
  --repeat 10 \
  --interval 0.5
```

参数说明：

| 参数 | 默认 | 说明 |
|------|------|------|
| `--repeat` | `1` | 调用次数 |
| `--interval` | `0` | 两次调用间隔（秒） |
| `--timeout` | `30` | HTTP 超时（秒） |
| `--photo` | — | 照片文件路径，或已是 Base64 字符串 |
| `--out-biz-no-prefix` | `latency-test` | 订单号前缀 |

## 3. 耗时统计说明

脚本会输出两类耗时（单位：毫秒）：

| 指标 | 含义 |
|------|------|
| `client_ms` | 客户端侧计时：`perf_counter()` 包裹整个 HTTP 请求（含 TLS、网络往返、服务端处理） |

多次调用时会额外输出：

- `min` / `max` / `avg`：最小、最大、平均耗时
- `p50` / `p95`：中位数、95 分位

示例输出：

```text
=== 身份证三要素核验 延迟测试 ===
endpoint: https://api.cqcucc.com:8443/api/idCardThreeElements
repeat: 10  interval: 0.5s

[#1/10] Code=0 IsCharge=True client_ms=842.3 Result=1
[#2/10] Code=0 IsCharge=True client_ms=756.8 Result=1
...

--- 耗时汇总 (client_ms, 单位 ms) ---
count=10  min=712.4  max=842.3  avg=778.6  p50=771.2  p95=831.5
```

> **注意**：上游成功响应（`Code=0`）会计费。压测前请确认账号余额与 QPS 限制，避免产生不必要的费用。

## 4. 示例代码（Python，含耗时统计）

完整可运行脚本见同目录：`test_idverify_latency.py`。

核心逻辑摘录：

```python
import hashlib
import json
import time
import uuid
import urllib.request

def sign_idverify(params: dict, app_secret: str) -> str:
    items = sorted((k, str(v)) for k, v in params.items())
    raw = "&".join(f"{k}={v}" for k, v in items) + f"&AppSecret={app_secret}"
    return hashlib.sha256(raw.encode("utf-8")).hexdigest()

def call_once(app_id, app_secret, name, id_card, profile_picture_b64, base_url, timeout=30):
    ts = int(time.time() * 1000)
    out_biz_no = f"latency-{uuid.uuid4().hex[:16]}"
    sign_params = {
        "appId": app_id,
        "outBizNo": out_biz_no,
        "name": name,
        "idCard": id_card,
        "profilePicture": profile_picture_b64,
        "timestamp": str(ts),
    }
    body = {
        **sign_params,
        "timestamp": ts,
        "signature": sign_idverify(sign_params, app_secret),
    }
    raw_body = json.dumps(body, ensure_ascii=False).encode("utf-8")
    req = urllib.request.Request(
        base_url, data=raw_body,
        headers={"Content-Type": "application/json;charset=UTF-8"},
        method="POST",
    )
    t0 = time.perf_counter()
    with urllib.request.urlopen(req, timeout=timeout) as resp:
        client_ms = (time.perf_counter() - t0) * 1000
        data = json.loads(resp.read().decode("utf-8"))
    return {"client_ms": client_ms, "http_status": resp.status, "response": data}
```

## 6. 常见问题

1. **405 签名校验错误**：检查 `&AppSecret=` 大小写、timestamp 在签名串中为字符串、profilePicture 是否参与签名。
2. **402 时间戳不合法**：服务器时间与北京时间偏差超过 60 秒，请同步 NTP。
3. **461 照片不符合要求**：Base64 后超过 50K，或现场照片小于 5K。
4. **409 IP 不在白名单**：需在上游平台配置服务器出口 IP。
