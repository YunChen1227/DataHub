收入A_g版

简要描述
  • 收入A_g版
请求URL
  • http://server:port/yrzx/common/v2/credit/v2(server:port在联调时提供)
获取密钥
  • https://www.showdoc.com.cn/p/eb985dca7743ec9fef0636e7ab4957c2
对接方式
  • 请求方式：http/post
  • 编码:UTF-8
  • 输出格式：JSON
  • 注：account与key由商户提供
输入参数
参数名称 是否必填 是否签名 参数描述
account 是 是 账户
type 是 是 接口类型（固定值:1106）
data 是 是 业务json串（通过3des+base64加密）
reqid 是 是 请求流水号不大于20位
verify 是 否 签名Md5(account+data(加密前json串)+reqid+type+key).toUpperCase
data输入参数
参数名称 是否必填 参数描述
name 是 姓名
cid 是 身份证号
mobile 是 手机号
返回参数
字段名称 是否签名 描述
code 是 返回码，具体见返回码字典
msg 否 返回码的中文描述，具体见返回码字典
uid 是 流水号
reqid 是 接入方生成的唯一查询流水号，长度 20 位以内
result 否 业务返回串，加密字符串
verify 否 签名
result二级节点
字段名称 描述
cbjfzt 缴费状态（1：正常；2：封存 ； 3：销户；）
jfjs 缴费基数，见收入A_g版字典
jfsj 缴费时间
返回码字典
返回码 描述
001 成功（计费）
999 无结果返回
002 账号不存在
003 余额不足
004 请给该账户授权
020 参数为空或格式错误
009 账号为空
011 verify为空或格式错误
012 接口错误，请联系提供商
013 校验签名错误
